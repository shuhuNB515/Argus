# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in ARTEX itself, do not disclose details in a public issue, discussion, or README. Use GitHub's private security reporting channel and include:

- the affected version or commit;
- reproducible steps and a minimal proof;
- the impact and suggested remediation;
- only the logs or screenshots needed to reproduce the issue, with secrets and personal data removed.

Do not attack third-party systems, access data, establish persistence, disrupt service, or expand impact to prove a report.

ARTEX is a security testing tool. Before testing any target, you must own it or have explicit authorization and must follow the target's scope and applicable law.
