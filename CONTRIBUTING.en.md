# Contributing

Thank you for your interest in Argus. Before submitting code, documentation, or an issue, read [README.md](README.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Issues

- Use a GitHub Issue template and include reproduction steps and the environment.
- Never publish API keys, passwords, personal data, or an unpatched security vulnerability in a public issue.
- Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).

## Changes

1. Keep each change focused and add appropriate tests.
2. User-facing text must be Chinese or English, with both locale resources kept in sync.
3. Do not commit `.env` files, secrets, databases, build outputs, or user data.
4. Run the relevant Go tests, frontend type checks, and production build before submitting.

## Safety boundary

Argus is limited to owned assets, explicitly authorized test ranges, and local labs. Do not perform unauthorized scanning, destructive testing, denial of service, or credential attacks against third-party systems.
