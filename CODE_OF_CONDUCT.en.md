# Code of Conduct

Argus welcomes lawful, respectful, and constructive participation. Use professional and inclusive language, and respect different experiences, viewpoints, identities, and backgrounds.

Harassment, discrimination, threats, doxxing, unauthorized attacks, and other unlawful conduct are not allowed. Security testing must target only systems that you own or are explicitly authorized to test.

Please report unacceptable behavior through the repository's private security channel with enough context to investigate. Maintainers will handle reports confidentially where reasonably possible.
